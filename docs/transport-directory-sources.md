# Fuentes de directorio de transporte terrestre

## Grupo Palomino / Wari

La ampliación del directorio toma como referencia la página oficial de destinos del Grupo Palomino y la ficha descriptiva de Kupos. Ambas fuentes confirman la cobertura hacia Abancay, Andahuaylas, Arequipa, Ayacucho, Camaná, Coracora, Cusco, Ica, Nasca, Puerto Maldonado y Puquio, además de puntos de venta en otras localidades. La página oficial publica como agencia principal **Av. Nicolás Arriola 906, La Victoria, Lima**, con teléfono **620-2333 anexo 100**, correo **ventatelefonica@tpalomino.pe** y WhatsApp **+51 997 769 702**.

Para direcciones regionales que no estén publicadas de forma verificable, el producto debe conservar la opción **Escribir sede manual** y mostrar el enlace al directorio oficial, evitando inventar una dirección específica.
