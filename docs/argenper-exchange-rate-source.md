# Fuente de cotización para transferencias PEN a EUR

La página pública de Argenper Perú publica cotizaciones de compra y venta de euros en su sitio web y en su página de tarifas. La interfaz de transferencias debe etiquetar este valor como **cotización de referencia de Argemper**, conservar la fecha/hora de consulta y permitir siempre una sustitución manual por el operador, ya que una cotización web puede cambiar antes de concretar la operación.

Para la regla solicitada de PEN a EUR, el sistema usa la cotización de referencia aplicable más **0,15 puntos**. El operador puede cambiar el tipo de cambio final antes de guardar, conservando el valor decidido en el recibo.
